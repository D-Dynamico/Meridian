# 2026-10-06 Planning

**Scope:** choose between Aereo's two take-home options, settle the stack, and write the
project docs before any code.

**Changes**
- Created `CLAUDE.md` and the full `docs/` set: architecture, API, CRS, decisions,
  workflows, test plan.

**Decisions**
- Chose the Geospatial File Measurement API over the Bulk Certificate Generator. Aereo is a
  drone survey and mapping company, so Shapefile, KML and CRS work matches their product
  directly; the certificate task is a generic backend exercise.
- FastAPI over Django + DRF (`DECISIONS.md` D1).
- Per-feature UTM projection with a geodesic cross-check (D2, D3).
- `BackgroundTasks` and SQLite to keep reviewer setup at zero dependencies (D4, D5).
- No external APIs. Everything runs offline with GeoPandas, Shapely and pyproj.

**Surprises**
- GeoPandas reads only the first layer of a multi-folder KML by default. Easy to miss and
  would silently drop features. Now a convention in `CLAUDE.md` and a test in §16.
