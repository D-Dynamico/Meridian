# Session Notes

One file per working session: `<YYYY-MM-DD>-<topic>.md`. The newest note is read at the
start of every session (see `CLAUDE.md`).

## Template

**Scope:** what this session set out to do.

**Changes**
- What changed, and the reason behind it. Cite § numbers where relevant.

**Decisions**
- What was decided, what was rejected, and why.

**Surprises**
- What nearly went wrong, behaved unexpectedly, or was found while writing a test or a
  commit message.

**Verification**
- How the changes were checked: tests run, manual uploads, mutation checks.

**Open items**
- What is left, in the order it should be picked up.
